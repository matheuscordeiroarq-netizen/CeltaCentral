# Celta Central PWA

PWA em modo paisagem para o iPad. Possui modo demonstração, controles de A/C, milha, módulo, destravar e porta-malas, além de área reservada para CarPlay.

Para instalar como PWA, publique os arquivos em um host HTTPS (por exemplo GitHub Pages), abra no Safari do iPad e use Compartilhar > Adicionar à Tela de Início. Depois da primeira carga, os arquivos principais ficam em cache para uso offline.

A integração com ESP32 será adicionada na função `send()` em `app.js`.
